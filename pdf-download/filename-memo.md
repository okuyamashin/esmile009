# PDFファイル名（メモ）

2026-08-25 確認。ダウンロード時のファイル名規則。

## 並び

受付番号・確定作業日・「報告書」・`_`・建物名・現地お客様名・様

末尾は **様** で終わる。  
「間隔」はもともと空白の予定だったが、JavaScript での扱いが悪いのでアンダースコアにする。「感覚」はタイポ。

## 各要素

| 順 | 内容 | 備考 |
|----|------|------|
| 1 | 受付番号 | TSV の `受付地域別受注番号` |
| 2 | 確定作業日 | 確定した作業日 |
| 3 | `報告書` | 固定文字 |
| 4 | `_` | アンダースコア。報告書と建物名のあいだ |
| 5 | 建物名 | TSV の `建物名`。空のときは住所の `住所（市区町村）` と `住所（その他）` |
| 6 | 現地お客様名 | 現地のお客様名 |
| 7 | `様` | 固定文字。ここで終わる |

## 例

建物名がある場合:

`B04-00063828_確定作業日_報告書_建物名_現地お客様名様`

建物名がない場合:

`B04-00063828_確定作業日_報告書_市区町村その他_現地お客様名様`

報告書の直後はアンダースコア。他の区切り文字は未指定。実装時に確認する。
