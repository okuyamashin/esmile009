# PDFファイル名（メモ）

2026-09-08 確認。個別ダウンロード時のファイル名規則。

## 並び

受付番号・確定作業日・「報告書」・全角スペース・建物名（なければ住所）・現地お客様名・様

`{受付番号}_{確定作業日}_報告書　{場所}_{現地お客様名}様.pdf`

受付番号・確定作業日・報告書のあいだ、および建物名とお客様名のあいだは **アンダースコア**。  
報告書の直後だけ **全角スペース（`　`）**。

## 各要素

| 順 | 内容 | 備考 |
|----|------|------|
| 1 | 受付番号 | TSV の `受付地域別受注番号` |
| 2 | 確定作業日 | TSV の `終了日時` の日付。`2026/08/22 18:30` → `20260822` |
| 3 | `報告書` | 固定文字 |
| 4 | 全角スペース | 報告書と場所のあいだだけ |
| 5 | 場所 | TSV の `建物名`。空のときは `住所（市区町村）` + `住所（その他）` |
| 6 | 現地お客様名 | TSV の `氏名`（クライアント名ではない） |
| 7 | `様` | 固定文字。ここで終わる |

## 例

終了日時が `2026/08/22 18:30` のとき。

建物名がある場合:

`B04-00063828_20260822_報告書　エスポワールOH72　101_クロキ様.pdf`

建物名がない場合:

`B04-00063828_20260822_報告書　杉並区阿佐谷南3-13-4ローソン阿佐谷青梅街道店_クロキ様.pdf`

`\ / : * ? " < > |` と制御文字は除去する。連結ダウンロードは `esmile009-{date}.pdf` のまま。
